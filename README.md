# My RAG AI

A simple Retrieval-Augmented Generation (RAG) AI application built with Python.

## Features

- AI-powered question answering
- Retrieval-Augmented Generation
- Uses a knowledge base to provide relevant answers

## Project Files

- `app.py` — Main application
- `test.py` — Testing
- `requirements.txt` — Python dependencies
- `.gitignore` — Keeps sensitive/unnecessary files out of GitHub
